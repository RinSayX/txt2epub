# 章节编号检查

[项目首页](../README.md) · [TXT 转 EPUB](TXT_TO_EPUB.md) · [自定义正则](REGEX_RULES.md)

导入 TXT 后，在文件信息下方点击“查看编号检查”。检查针对当前识别与纠错后的有效目录，自动跟随导入、应用规则、合并、删除空章节、撤销和重做更新。EPUB 可先转换为 TXT，再导入工作台检查。

## 默认设置与范围

- 默认采用“全书连续”，勾选“章、回”。不同编号类型与层级各自形成序列，跨卷继续比较。
- 选择“按卷／册分别检查”后，以已识别的最近更高层级卷或册划分序列，各组可以重新编号。卷与章配置成同一层级时，卷不会作为章的重置边界；没有识别到上级卷／册的内容仍在全书范围内检查。
- 可勾选当前目录出现的卷、册、其他自定义编号关键词或正则编号系列。未勾选的编号标题计入“范围外”，不算作解析失败。
- 自动“简介”、序章、楔子、尾声、后记及普通无编号标题不参与比较，也不单独重置编号序列。分卷边界按识别到的卷/册判断，不因穿插无编号标题而消失。
- 只检查组内已有的最小与最大编号之间的缺口。节选从第 300 章开始不会报缺少前 299 章，也不会推断结尾还缺多少章。

## 结果含义

| 类别         | 示例                       | 判断方式                               |
| ------------ | -------------------------- | -------------------------------------- |
| 疑似缺号     | 10、13                     | 当前范围内缺少 11–12，合并为一个范围   |
| 重复         | 10、11、10                 | 同号出现两次，列出每次的标题和原文行号 |
| 顺序异常     | 10、12、11                 | 11 出现在 12 之后；不误报缺少 11       |
| 未解析的编号 | 第一百百章                 | 已识别为标题，但不能明确转换为数值     |
| 允许的分篇   | 第10章（上）、第10章（下） | 默认视作同号的不同分篇，单独列出       |

缺号通过检查整个序列的不同编号判断，顺序通过原文相邻编号判断，因此 `1、3、2、4` 仅提示顺序异常。非相邻重复也能检查；一次跳过大量编号只生成一条范围结果。重复与顺序异常可能同时存在，按不同问题分别展示。

编号异常不证明正文丢失或重复。疑似缺号可能来自原文件缺章、标题写法特殊、规则未匹配或人工取消/删除标题；重复编号也可能是原书有意采用的编号。先查看相关正文与原文件，再决定是否调整识别规则或标记已确认。功能不会改写编号、补写内容或阻止导出。

## 数字与分篇

支持阿拉伯数字、全角数字、逐位中文数字及常见中文单位、大写数字，例如 `233`、`２３３`、`二〇三`、`两百`、`第二百三十三章`、`第贰佰叁拾叁章`。数字转换仅用于比较，显示和导出的原标题保持原样。

启用[前置序号示例](REGEX_RULES.md#快速处理带前置序号的章节)后，`999.第233章 比试` 按里面的 `233` 检查。标题正文中的年份等普通数字不自动当作编号。不明确的口语数字如“二百三”“一万二”、损坏数字或超出 JavaScript 安全整数范围的数字，会列为未解析，不猜测数值。原本未识别为章节的行不会出现在“未解析”列表中，仍需核对识别规则。

默认允许编号之后明确标记的 `（上）`、`（中）`、`（下）` 及半角括号形式共用编号；无需三篇齐全，缺少某个分篇不作为缺号报告。相同编号的同一分篇重复仍提示重复，下篇出现在上篇之前会提示顺序异常。“上山”“下雨”等普通标题词不当成分篇。

勾选“严格检查同号章节”后，所有同号标题都列为重复候选，包括上中下分篇。没有明确分篇标记的同号章节也会按重复检查。

## 自定义正则的 number 捕获组

若显示标题已保留标准编号，如现有的 `233.第233章 比试` 示例，通常无需修改表达式。

若显示标题会去掉编号，可使用可选的 `number` 命名捕获组：

```regex
^(?<number>[0-9０-９]+)[.．]\s*(?<title>.+)$
```

输入 `233. 比试` 时，显示标题为“比试”，编号为 `233`。应用规则后，在编号检查的“检测对象”中勾选对应的“正则：规则名”系列。该系列初始不自动勾选；默认只检查章、回。

- 显式 `number` 组优先；没有该组时，尝试从显示标题、再从原标题提取标准“第…章/回/卷/册…”格式。
- 无法确定类型的正则按规则 ID 划分系列；能提取标准类型的按类型与层级检查，可与同层级的关键词规则形成同一序列。
- 空或无效的 `number` 只影响编号检查，不让原本有效的标题匹配失败，也不会改变 `title` 的原有行为。
- 匹配仍在现有独立正则 Worker 内执行，主线程不重新执行用户正则。规则语法、测试方式和超时说明见 [正则使用指南](REGEX_RULES.md)。

## 定位、确认和取消

- 可筛选全部待确认、缺号、重复、顺序异常、未解析编号、允许分篇及已确认问题。每次展示 50 条结果，重复位置较多时先展示 20 处，再逐步展开。
- 点击原文行号会关闭窗口、切换回目录、清除目录搜索、展开所属父级，并选中对应章节显示正文。
- “标记已确认”会从待确认统计中排除该问题，可在已确认列表恢复。关闭并重新打开检查窗口保留标记；修改目录或检查设置后清除全部确认并重检。
- 检查设置与确认仅在当前页面会话内保存，不写入 TXT/EPUB 或浏览器持久存储。刷新页面后需重新导入。
- 检查有进度及取消入口；取消后可点击“重新检查”。检查结果绑定文档 ID、目录版本和设置，目录变化时不会继续展示旧结果。尚未应用的规则草稿不会改变检查结果。
