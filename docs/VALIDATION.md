本轮复验范围为本地自动测试、构建和文档检查。未重跑浏览器下载、EPUBCheck 或阅读器实机验收；下文的历史结果仅对应当时的样本和实现。

移动界面调整后，另用内置浏览器的 320、360、390 px 竖屏及 667 × 375 横屏视口检查生产预览。验证了目录与正文切换、搜索和折叠保留、规则操作、编号定位、自动封面导出及 EPUB 转 TXT。1200 px 视口确认桌面仍显示双栏。双向转换均看到下载开始提示；未在手机真机上验证软键盘和文件保存。

## 如何复现

| 命令                               | 用途                                                      |
| ---------------------------------- | --------------------------------------------------------- |
| `npm test`                         | 常规核心、组件、Worker 和下载适配器测试；默认跳过规模用例 |
| `npm run test:scale`               | 启用 `RUN_SCALE` 并运行规模与 Worker 测试目录             |
| `RUN_SCALE=1 npm test`             | 在同一轮运行常规测试和所有规模用例                        |
| `npm run build`、`npm run preview` | 本地生产预览，用于检查实际界面和 Worker 加载              |
| `npm run format:check`             | 检查代码和 Markdown 格式                                  |

核心覆盖编码、层级、源文边界、纠错与还原、正则隔离、章节编号、正文空白、XML 转义、封面、NAV／NCX／OPF 引用、拆片和 TXT 提取。Worker 回归还包括导入后的编号检测、过期请求拒绝、超时／取消与原会话保护。

### 规模样本

合成样本使用重复段落，实际字节数会略高于目标。规模检查验证识别出的标题与导出段落数量，并检查 16,000 章节的导出资源数；另有单独的 Worker 用例读取实际 51 MiB 文件并分页预览。

| 目标文本大小 | 实际章节 | 导出正文段落 |
| ------------ | -------: | -----------: |
| 约 1 MiB     |       55 |       11,000 |
| 约 10 MiB    |      547 |      109,400 |
| 约 20 MiB    |    1,093 |      218,600 |
| 约 51 MiB    |    2,786 |      557,200 |

测量详情和导出样本由规模测试写入 `artifacts/scale-results.json`、`artifacts/scale-20MiB.epub` 和 `artifacts/scale-51MiB.epub`。它们是本地合成验收产物，不纳入 Git；压缩率、耗时和内存消耗不代表实际小说或浏览器表现。

## 历史实测

| 范围            | 已观察到的结果与边界                                                                                                                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TXT 导入与纠错  | 生产预览通过示例导入、GBK 推测及正文核对、空文件错误、合并、删除空卷、子节保留、重算、撤销和重做。恰好 20 MiB 的 TXT 验证过导入、分页预览、取消后重新导出及实际 EPUB 下载。                                                   |
| EPUB 源码和正文 | 早期验证过 XHTML 源码换行及缩进、段首和章末空白清理、段间空行开关、非法 C0 默认报错与按需清理。移除导出样式后，重新解包 20／51 MiB 样本核对无 CSS 声明、正文段落和 manifest 引用；这不是重新运行 EPUBCheck。                  |
| 自定义正则      | 生产预览验证前置序号、标题提取、应用规则、纠错及导出。以长回溯表达式验证约 2 秒无进度时终止，并核对取消或规则错误后原目录保留。                                                                                               |
| 自动封面        | 浏览器下载过带自动封面的样本；解包验证 600 × 800 PNG、首个 spine 项、manifest 引用、XML 和无 CSS。该样本未重跑 EPUBCheck；历史目视验证不等同于所有后续字号调整的验收。                                                        |
| EPUB 转 TXT     | 浏览器验证两份正文文档的顺序、标题、中文、emoji、预览，关闭转换窗口后原 TXT 工作台保留；大文本样本取消后可重试。点击“下载 TXT”已触发提示，但自动化未取得落盘路径。UTF-8 字节、Blob 和命名已在自动测试核对，浏览器落盘未确认。 |
| 章节编号        | 浏览器样本全书模式为缺号 1 处、重复 3 组、顺序异常 2 处；按卷检查为缺号 1、重复 1、顺序异常 1。验证严格分篇、确认筛选、从折叠与搜索状态定位，以及合并／撤销后重检。                                                           |

更早的逐次回归数据、截图文件名及工具输出范围见[整理前的完整记录](https://github.com/RinSayX/txt2epub/blob/98c4e0b/docs/VALIDATION.md)。

## EPUBCheck 与实机

历史上使用 [EPUBCheck 5.4.0](https://github.com/w3c/epubcheck/releases/tag/v5.4.0) 本地检查过示例 EPUB、20 MiB 导出样本及后来增加的 51 MiB 规模样本，所记录的对应运行均为 0 fatal／0 error／0 warning／0 info。该版本使用 EPUB 3.4 规则检查 EPUB3，生成器的 OPF 版本值仍为 `3.0`。这些历史通过结果不覆盖本轮新生成的样本。

如需复验，使用本机安装的 EPUBCheck 检查代表性文件（例如普通、带封面、长章节拆片各一本）：

```sh
java -jar /path/to/epubcheck.jar /path/to/book.epub
```

报告应记录检查器版本、输入样本、生成代码版本及错误／警告。规范通过不代表设备实机兼容；目标阅读器和版本尚未指定，未进行实机兼容验收。
