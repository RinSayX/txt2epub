# TXT 转 EPUB 使用说明

[项目首页](../README.md) · [自定义正则](REGEX_RULES.md) · [章节编号检查](NUMBERING_CHECK.md)

## 导入与整理

1. 点击“导入 TXT”或将 `.txt` 拖入导入区。也可点击“试用示例小说”。
2. 在文件信息栏核对编码和正文。自动检测优先识别带 BOM 的 UTF-16、再尝试严格 UTF-8；必要时在 GB18030 和 Big5 中推测。手动还可选择 GBK 和 UTF-16 LE／BE。自动推测的传统编码需要人工核对，尤其是生僻字和标点。
3. 在“识别规则”修改关键词或层级，点击“应用识别规则”。默认层级为卷 → 册 → 章 → 回，层级数字越小越高；也支持序章、楔子、尾声、后记和番外等无编号标题。特殊格式可使用[自定义正则](REGEX_RULES.md)。
4. 在目录搜索、折叠和切换章节，结合正文检查误判。可通过[编号检查](NUMBERING_CHECK.md)定位疑似缺号、重复或顺序异常。
5. 点击“导出 EPUB”，填写书名，按需选择作者、语言和导出选项，再生成并下载。

零字节和纯空白 TXT 会报错。大于 50 MiB 的文件显示提示后继续处理，恰好 50 MiB 不提示。首个有效标题前的文字归入“简介”；没有识别到标题时，整本按单节导出，节标题使用书名。

| 纠错操作               | 效果                                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 并入上一节             | 取消选中的标题，将原始标题行及其直属正文保留为上一内容段的正文。没有上一段时，保留为卷首内容；若没有剩余标题则整本按单节处理。 |
| 删除空章节／清理空章节 | 删除选中或所有直属正文为空的标题；原标题不并入正文。空的卷、册也适用，即使它们含有子章节。                                     |
| 撤销／重做             | 还原或重做合并、删除操作，快捷键为 `⌘/Ctrl Z` 和 `⌘/Ctrl Shift Z`。                                                            |

两类纠错都会保留子章节并重建层级。重新应用识别规则保留当前纠错；重新导入或切换编码时，已有纠错或撤销记录会触发重置确认。任何操作都不会写回原 TXT。

## 导出选项

- **书名、作者和语言**：书名必填，默认取文件名去掉 `.txt`；作者选填。简体中文（默认）为 `zh-CN`，繁体中文为 `zh-Hant`，英文为 `en`。语言写入 OPF 元数据和 XHTML，不转换正文的文字或语种。
- **自动生成封面**：默认关闭。开启后可预览 600 × 800 的白底黑字 PNG，只显示书名，不加书名号。起始字号为 72 px，按实际字宽换行，必要时缩小；字体取决于设备上的可用字体，不请求网络字体。
- **清理段间空行**：默认关闭，与预览区共用同一个开关。开启后省略空白行，正常段落仍各自独立。
- **清理不兼容的隐藏控制字符**：默认关闭，仅对本次导出有效。出现 U+001A 等错误时可开启，清理正文和章节标题中的非法 C0 控制字符。会提示清理数量，保留 TAB、LF、CR 及其他合法文字；不会改变预览或源文件。书名、作者中的非法字符或损坏的 Unicode 需手动修正。

预览与导出都会去掉段首的空格、制表符等横向空白和章末空白行，保留正文行内空格和非空段的段尾空格。每个非空行单独成段，不自动拼接。导出 EPUB 不附带 CSS，阅读器可折叠连续空格，并根据自身设置决定字号、缩进和分页。

## XHTML 文件命名与拆片

正文文档位于 `OEBPS/text/`，按实际生成文件的顺序从 1 编号，数字补齐至少六位，例如 `section-000001.xhtml`。简介、卷、册等内容段和长章节拆片都占一个文件编号。编号不是小说章号，也不是跨导出固定的 ID。

假设有简介、一卷、拆成两片的第一章和一篇第二章：

| 文件名                 | 内容                 |
| ---------------------- | -------------------- |
| `section-000001.xhtml` | 简介                 |
| `section-000002.xhtml` | 第一卷及其直属正文   |
| `section-000003.xhtml` | 第一章标题及正文首片 |
| `section-000004.xhtml` | 第一章续片           |
| `section-000005.xhtml` | 第二章               |

正文标记以约 250 KiB 为软拆分目标，只在段落边界拆分；单段本身过长时可能超过该值。NAV 和 NCX 指向首片的标题，OPF spine 列出所有拆片。封面页单独使用 `OEBPS/cover.xhtml`，不占正文编号。

文件名不包含标题，便于排序，也避免因重名或特殊字符产生冲突。手动编辑 EPUB 时可从编辑器目录跳到章节首片，再在 spine 中找续片。前面增删内容段或改变拆片数，后续文件编号可能随之移动。

## 常见问题

| 现象                       | 处理方式                                                                                                                                     |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 乱码或解码失败             | 切换到原文件实际使用的编码。自动解码成功不代表判断一定正确。                                                                                 |
| 疑似缺章                   | 点击编号问题定位；先确认原标题是否被误认成正文，再判断源文件是否缺章。                                                                       |
| 无法导出，提示规则尚未应用 | 先应用更改后的识别规则。编号告警本身不阻止导出。                                                                                             |
| 提示 XML 不支持的字符      | 错误行号从 1 开始，偏移按统一换行后的工作文本 UTF-16 索引从 0 开始；删空章后偏移可能不同于原文件。按提示修正，或对非法 C0 字符使用可选清理。 |
| 阅读器显示与网页预览不同   | 网页用于校对文字和目录，实际排版以阅读器为准；只导出 EPUB3，附带 NCX 不等于生成 EPUB2。                                                      |

需要检查包结构时，可参考[技术设计](TECHNICAL_DESIGN.md)与[验证方法](VALIDATION.md)。
