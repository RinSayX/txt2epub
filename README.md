# 拾页 · TXT 小说转 EPUB

纯浏览器本地处理的小说整理与转换工具。导入 TXT、整理章节、预览正文，导出带有多层目录的 EPUB3 电子书。小说不上传到服务端。

## 本地运行

推荐 Node.js 24，使用 npm 安装依赖：

```sh
npm ci
npm run dev
```

项目通过 `.npmrc` 使用当前目录下的 `.npm-cache/` 缓存，避免用户全局 npm 缓存的权限问题。该缓存已加入 `.gitignore`，安装时无需修改全局目录权限。

打开终端显示的本机地址（默认 `http://127.0.0.1:5173`）。首次运行需联网安装依赖。依赖安装完毕后，转换过程无需联网；静态网页首次加载仍需要本地或远程服务器。

```sh
npm run build     # 类型检查并生成 dist/
npm run preview   # 预览构建产物
npm test          # 编码、识别、纠错、EPUB 结构与内容测试
npm run test:scale # 1/10/20/51 MiB、Worker 导入逻辑及 16000 章节验收
```

`dist/` 可部署到静态托管服务，无需后端。请通过 HTTP(S) 访问，直接双击 HTML 文件不支持 Worker 和模块加载。

## 已实现功能

- 支持导入大文件 TXT，不设置文件大小硬上限。仅超过 50 MiB 时提示可能需要更多时间和内存，仍自动继续导入；恰好 50 MiB 不提示。实际处理能力取决于浏览器和设备资源。
- 支持 UTF-8、GBK、GB18030、Big5、UTF-16LE/BE，提供自动判断与手动切换。
- 自动识别中文数字、阿拉伯数字、全角数字章节编号。
- 多层章节目录，默认“卷 → 册 → 章 → 回”；支持关键词增删、启停、层级排序和同级关键词。
- 支持“序章、楔子、尾声、后记、番外”等无编号标题及带明确分隔符的副标题。
- 可搜索、折叠的目录；正文按需预览、分页加载，可调整预览字号。
- 将误判标题并入上一节：原标题行保留为正文，子章节保留并重建层级；支持撤销/重做和快捷键 `⌘/Ctrl Z`、`⌘/Ctrl Shift Z`。
- 调整识别规则后保留当前文件的纠错记录；更换文件或编码前提示重置纠错。
- 预览与导出统一去除每段开头的空格、全角空格和制表符，以及章节末尾的所有空白行；保留段落之间的空行、行内和段尾空格及特殊字符，不自动拼接自然段。源 TXT 不变。
- 编辑书名、可选作者及语言；导出 EPUB3，包含 NAV 与 NCX 多级目录、OPF 阅读顺序和 UTF-8 XHTML。
- EPUB 内的 XHTML、OPF、NCX、XML 和 CSS 使用换行及两空格缩进，方便在电子书编辑器中修改；每个正文段落独立一行，代码缩进位于标签之外，不会成为正文缩进。
- 长章节按段落拆分为内容文件，解析与导出在 Web Worker 中运行，提供进度和取消。
- 自带合成示例小说，可直接体验并纠正一处有意保留的误识别。

## 使用方法

1. 选择 TXT 或拖入中央导入区，也可点击“试用示例小说”。
2. 检查正文编码；若乱码，在文件信息栏手动切换。自动推测的传统编码需人工核对。
3. 在“识别规则”添加关键词、选择层级，点击“应用识别规则”。层级数字越小，级别越高。
4. 在目录选中误识别的标题，点击“并入上一节”。如果没有上一节，内容归入“前言”。
5. 点击“导出 EPUB”，填写信息，生成并下载电子书。

小说和纠错记录仅保留在当前页面会话中，刷新或关闭页面后需重新导入。浏览器本地存储仅保存识别规则，不保存小说正文。

## 验证与兼容范围

核心测试覆盖编码、多层与缺层目录、误判合并及还原、原文区间完整性、特殊字符转义、NAV/NCX/manifest/spine 引用及长章节拆分。

浏览器操作已验证示例导入、误判合并、撤销、重做、自定义规则重算和实际下载。浏览器生成的示例文件通过 EPUBCheck 5.4.0：0 fatal、0 error、0 warning。

另已通过 1/10/20/51 MiB 和 16,000 章节规模测试，Worker 导入逻辑使用真实 51 MiB 文件完成读取和预览验证。浏览器已验证恰好 20 MiB 文件的导入、取消导出和重新导出；已验证的导出样本通过 EPUBCheck。详情见 [VALIDATION.md](VALIDATION.md)。

如已安装 EPUBCheck，可在本机检查导出文件：

```sh
java -jar /path/to/epubcheck.jar /path/to/book.epub
```

只输出 EPUB3。附带 NCX 以增强旧阅读器兼容性，不承诺符合 EPUB2 或兼容全部旧设备；目标阅读器尚待指定及实机验证。页面预览用于文本和目录校对，不模拟阅读器分页。

单个超长段落不会被强行改写，250 KiB 的 XHTML 拆分阈值为按段落拆分的软目标。发现 XML 不支持的控制字符时，导出会定位提示并阻止生成，不静默删除。

## 技术结构

React + TypeScript + Vite，fflate 打包 EPUB；核心解析和导出与 UI 分离。

```text
src/core/          文本解码、章节识别、源文区间、EPUB 生成
src/workers/       文档 Worker 与进度、取消
src/components/    章节目录、识别规则、弹窗
src/App.tsx        导入、预览、纠错历史与导出流程
tests/             核心、EPUB 结构、规模验证
```

详细需求决定、架构和验收标准见 [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md)。
