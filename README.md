# 拾页 · TXT 与 EPUB 本地互转

简体中文 · [English](README.en.md)

拾页是面向小说的浏览器转换工具。可以把 TXT 整理成带多级目录的 EPUB3，也可以从未加密的 EPUB2／EPUB3 提取 UTF-8 TXT。转换在设备上完成，小说文件不上传。

[在线使用拾页](https://rinsay.com)

## 快速开始

推荐使用 Node.js 24。首次安装依赖需要联网：

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5173/`。没有文件时，可以点击“试用示例小说”。页面顶部可切换中英文，也可通过 `?lang=en` 直接打开英文界面。

| 想做什么           | 操作                                                  |
| ------------------ | ----------------------------------------------------- |
| TXT 转 EPUB        | 导入或拖入 TXT，核对编码和目录，点击“导出 EPUB”       |
| 检查缺章或重复编号 | 导入 TXT 后点击“查看编号检查”，按原文行号定位         |
| EPUB 转 TXT        | 点击顶部“EPUB 转 TXT”，选择文件，预览后点击“下载 TXT” |

`npm ci` 使用项目内的 `.npm-cache/`。如果仍遇到缓存权限问题，可以用 `npm ci --cache ./.npm-cache`，并确认该目录可写，无需用 `sudo` 安装项目依赖。

## 功能与边界

- **整理 TXT**：支持 UTF-8、GBK、GB18030、Big5、UTF-16 LE／BE；可配置关键词、多级目录和自定义正则。支持搜索、分页预览、合并误判标题、删除空章节、撤销和重做。
- **检查编号**：默认检查全书的“章、回”，可切换按卷／册检查。提示疑似缺号、重复和顺序异常，支持同号分篇及原文定位。检查结果不改动原文，也不阻止导出。
- **导出 EPUB3**：支持书籍元数据、可选 600 × 800 PNG 封面，以及空行和隐藏控制字符清理。导出文件不附带 CSS；同时生成 NAV 与旧式 NCX，具体显示效果和旧阅读器兼容性取决于目标设备。
- **提取 EPUB 文本**：按书内阅读顺序提取正文，提供预览及 UTF-8 TXT 下载；图片和排版不会写入 TXT，不支持 DRM 加密正文或 OCR。转换窗口独立于 TXT 工作台。
- **大文件与隐私**：超过 50 MiB 时提示，不设固定大小上限；实际能力取决于设备内存和浏览器。小说与纠错记录仅留在当前会话；浏览器本地存储只保存已应用的识别设置和界面语言。

## 构建与验证

```sh
npm run build         # TypeScript 检查并构建到 dist/
npm run preview       # 在本机预览生产构建
npm test              # 常规测试
npm run test:scale    # 合成大文件、16,000 章节及 Worker 回归
npm run format:check  # 检查格式
```

`dist/` 可部署到静态托管服务，无需后端。请通过 HTTP(S) 访问，直接双击 HTML 无法正常加载模块和 Worker。网页及其资源加载后，转换本身无需联网。

项目使用 React、TypeScript、Vite、fflate 和 xmldom。依赖、缓存、构建结果以及本地验证样本不纳入 Git。
